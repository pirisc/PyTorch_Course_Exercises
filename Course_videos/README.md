**PyTorch Course Videos Exercises**

* Overview*

This repository contains the Jupyter notebooks coded while follow along the PyTorch for Deep Learning Course.

*Course_videos:* 
 * `00_pytorch_fundamentals.ipynb` - introduction to Tensors
 * `01_pytorch_workflow.ipynb` - introduction to PyTorch workflow
 * `02_neural_network_classification_with_pytorch.ipynb` - Classification problems
 * `03_pytorch_computer_vision.ipynb` - Computer vision with PyTorch
 * `04_pytorch_custom_datasets.ipynb` - Using PyTorch with Custom Datasets
 * `05_pytorch_going_modular_cell_mode.ipynb` - creating Scripts
 * `05_pytorch_going_modular_script_mode.ipynb` - creating Scripts
 * `06_PyTorch_Transfer_learning.ipynb` - using Transfer Learning with PyTorch
 * `07_pytorch_experiment_tracking.ipynb` - tracking experiments using PyTorch
 * `08_pytorch_paper_replication.ipynb` - learn how to replicate papers
 * `09_Pytorch_model_deployment.ipynb` - deploy models with Gradio
